# **App Name**: CaseLink

## Core Features:

- Case File Creation: Lawyers can create new case files with core details: case number, client details, court, current status, and key dates. They can also archive old cases.
- Document Upload: Lawyers can upload essential documents to each case file, which are then stored securely.
- AI Tagging Tool: Tool which leverages a Large Language Model to intelligently suggest relevant tags for uploaded legal documents, making them easier to find.
- Hearing Reminders: Automated email notifications for upcoming court dates. The LLM tool determines the appropriate reminder schedule based on the case and hearing type.
- User Dashboard: User-friendly dashboards that allow Lawyers and Clients to view all active and inactive cases, documents, and hearing dates.

## Style Guidelines:

- Primary color: A professional blue (#3B82F6) to inspire confidence and reliability, appropriate for a legal setting.
- Background color: Light gray (#F7F7F7), offering a clean and neutral backdrop to focus on content.
- Accent color: A subdued purple (#8B5CF6), positioned analogously to blue, for calls to action.
- Clean and readable sans-serif font for the main content to ensure legibility and professionalism.
- Simple, clear icons that correspond to common legal terms and actions.
- Clean and structured layout to allow easy navigation.
- Subtle animations, such as a loading animation when generating suggested tags for a document.
